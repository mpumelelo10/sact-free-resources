## Live

You can enable GitHub Pages on this repository to host the site for free:

1. Go to **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / root
4. Save

Your site will be available at:
`https://mpumelelo10.github.io/sact-free-resources/`
