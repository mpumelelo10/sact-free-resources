Project Lessons

Welcome to your first real AWS project. We’ll keep costs near zero using Free Tier, clean up resources at the end, and focus on understanding why each service is used.
⏱ ~10 min
See the full architecture before writing any code:
  • API Gateway receives the request
  • Lambda runs the logic
  • DynamoDB stores the fun facts
  • Bedrock makes facts witty (optional GenAI version)
  • Amplify hosts the simple frontend
⏱ ~15 min
Create your first Lambda function that returns a hard-coded fun fact. Then expose it with API Gateway so you can call it from a browser or Postman.
  • Create Lambda function (Node.js or Python)
  • Add a simple GET endpoint
  • Test in the browser
⏱ ~30–40 min
Move the facts into DynamoDB so you can scale and update them easily.
  • Create a DynamoDB table
  • Seed a few cloud fun facts
  • Update Lambda to read a random fact
  • Practice IAM permissions for DynamoDB
⏱ ~40–50 min
Use Amazon Bedrock to rewrite or generate fun, witty versions of the facts. This is a gentle introduction to generative AI on AWS.
  • Enable Bedrock model access
  • Call the model from Lambda
  • Return a more engaging fact
⏱ ~30–40 min
Build a clean, mobile-friendly page that calls your API and shows a new fact on button click. Host it with Amplify Hosting (or even GitHub Pages / Netlify).
⏱ ~40 min
Always clean up. Delete the Lambda, API Gateway stage, DynamoDB table (if not needed), and any Amplify apps. Learn how to read the AWS Billing dashboard and set a budget alert.
⏱ ~15 min
You now have a real project for your portfolio. Next ideas:
  • Add a “Share this fact” button
  • Store user favourite facts
  • Add authentication with Cognito
  • Deploy to your own domain
Share your project in the Sip & Cloud community!
⏱ ~10 min
Practical tip from Pinky Build in small steps and test after every change. Screenshot your architecture and final working page — these make excellent LinkedIn and CV material.
